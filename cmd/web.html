Security

If you suspect someone got at this server or its data: hakobu issues new database passwords, storage keys, Sentry keys, GitHub webhook secret and Cloudflare tunnel token, restarts the apps with them, signs everyone out, disconnects AI apps and rotates the master key. It then lists what only you can replace.

{{if .KeyDownloaded}}You have a copy of the current master key.{{else}}You have no copy of the current master key: without it the panel's backups can't be restored.{{end}}

Download master key

Secrets, logs and the apps' errors are encrypted with the master key (key/master.key on this server), and so are all backups and the database snapshots for Rollback. Downloading it asks you to sign in with GitHub again. Keep the file away from this server, and download it again after replacing all secrets: the old one doesn't open newer backups.
